# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Email **security@revnix.io** with:

- what you found and where (this SDK, the Revnix API, or the dashboard)
- the steps or code to reproduce it
- the impact you think it has

We reply within 24 hours and keep you updated until the issue is fixed. Please give us a reasonable time to fix it before you talk about it publicly.

## Rules for testing

- Only use apps, accounts and data you own.
- Do not access or change other customers' data.
- Do not run tests that slow down or break the service.

We will not take legal action against research done in good faith under these rules.

## Supported versions

Security fixes ship in the latest release. Please update to it before reporting an issue you found in an older version.
